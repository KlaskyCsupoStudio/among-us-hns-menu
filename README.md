# Hide n Seek Menu

An Android-first prototype for a configurable Among Us Hide n Seek menu.

## Current status

- [x] HTML menu prototype
- [x] Local seeker-count setting prototype
- [ ] Android app packaging
- [ ] Compatible game integration
- [ ] Private-lobby testing

## Planned setting

Seeker Count: 1, 2, or 3.

## Important

This repository is currently a prototype. It does not modify
Among Us or change multiplayer role assignment.

Game integration depends on compatible modding tools,
the game version, and applicable multiplayer requirements.

## Development

The prototype uses HTML, CSS, and JavaScript.
The configuration experiment uses Python.

## Compatibility

Target game: Among Us for Android, version reported as v19.
Compatibility has not yet been verified.
